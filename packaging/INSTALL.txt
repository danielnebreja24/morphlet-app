Morphlet — installation
=======================

1. Drag Morphlet into your Applications folder.

2. Open it. Double-click it in Applications, or press Command-Space, type
   "Morphlet" and hit Return.

3. Allow Screen Recording when macOS asks. Morphlet needs this because the
   fold effect is a live mirror of your desktop — there is no way to bend what
   is on screen without first being able to see it. If you miss the prompt,
   grant it in System Settings > Privacy & Security > Screen Recording, then
   open Morphlet again.

Morphlet has no Dock icon and opens no window. Look for its glyph in the menu
bar, at the top right of your screen. To reopen it later, Command-Space and
type "Morphlet" is usually quickest.

Then close your lid.


What Morphlet does with your screen
-----------------------------------

Nothing leaves your Mac. Morphlet contains no networking code and writes no
image data to disk. Captured frames go from the system compositor straight into
GPU memory and are discarded. The only thing it stores anywhere are six
preference values: the three effect sliders, the two trigger angles, and
whether the effect is switched on.

Capture only runs while the lid is on its way down. With the lid open past the
trigger angle, no capture is running at all.

Morphlet is signed with an Apple Developer ID and notarized by Apple, which is
what lets it open without a security warning.


Requirements
------------

- macOS 14 or later
- A MacBook whose hinge reports an angle. Most Apple silicon MacBooks do. On
  hardware that does not, Morphlet still runs, but the effect snaps between
  flat and folded instead of tracking the lid, and the menu says so.


Upgrading from 0.1
------------------

Version 0.1 was signed with a self-signed certificate. This build is signed
with an Apple Developer ID instead, so macOS sees a different signature and
will ask for Screen Recording permission once more. That is a one-time step;
later versions keep the same identity and will not ask again.


Uninstalling
------------

Quit Morphlet from its menu, then drag Morphlet.app to the Trash. To remove its
preferences as well:

    defaults delete com.danielnebreja.morphlet
